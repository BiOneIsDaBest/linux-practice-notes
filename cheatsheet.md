# Linux Cheatsheet — Commands I Have Actually Used

Only commands I have run myself during practice are added here.

| Command | What it does | Example | Where I used it |
|---|---|---|---|
| `ssh` | Connect to a remote machine | `ssh bandit0@bandit.labs.overthewire.org -p 2220` | Bandit Level 0 |
| `whoami` | Show the current user | `whoami` | Bandit 0 → 1 |
| `ls -la` | List all files, including hidden ones, with permissions | `ls -la` | Bandit 0 → 1 |
| `cat` | Print a file's contents | `cat readme` | Bandit 0 → 1 |
| `cat ./<file>` | Read a file with a special name using a relative path | `cat ./-` | Bandit 1 → 2 |
